Local-first, sérieusement

Tes manuscrits ne sortent pas de ta machine

La plupart des outils d'écriture modernes sont en réalité des collecteurs de données déguisés en éditeurs. Studio Roman fait exactement le contraire.

01

Stockage 100 % local

Tes textes vivent dans une base SQLite sur ton disque dur. Aucun compte serveur, aucune télémétrie marketing, aucun envoi automatique.

02

IA optionnelle

Ollama en local pour rester déconnecté, ou OpenAI / Anthropic / Gemini si tu fournis ta clé API. Studio Roman ne facture jamais l'IA.

03

Sauvegarde opt-in

Si tu actives la synchro Google Drive ou Dropbox, le fichier va de ton appareil vers ton compte. Studio Roman n'y a pas accès.

04

Code ouvert

Le code source est public sur GitHub. Tu peux vérifier, auditer, ou contribuer. Aucune boîte noire.

Le logiciel d'écriture francophone pour les écrivains exigeants

Choisir un logiciel pour écrire un roman n'est pas anodin. Word a été pensé pour les rapports d'entreprise, Google Docs pour la collaboration de bureau, et la plupart des outils en ligne sont aujourd'hui des plateformes SaaS qui stockent ton manuscrit sur leurs serveurs en échange d'un abonnement mensuel. Pour un romancier, aucun de ces outils ne pose les bonnes questions.

Studio Roman est un logiciel pour écrivains conçu autour des trois besoins fondamentaux du travail romanesque : structurer (chapitres, scènes, arcs), tenir la cohérence (personnages, lieux, chronologie), et livrer un manuscrit propre (export DOCX pour l'éditeur, EPUB pour le numérique, PDF pour l'impression). Ce sont les trois choses qu'un éditeur de texte généraliste ne fera jamais correctement.

Une vraie alternative à Scrivener, en français et gratuite

Scrivener reste la référence côté anglophone, mais son interface française est lacunaire et son prix non négligeable. Studio Roman propose une alternative à Scrivener pensée nativement pour les auteurs francophones : intégration de Gramalecte et LanguageTool directement dans l'éditeur, terminologie en français, dictionnaires français par défaut, et — surtout — gratuité totale.

Pour l'autoédition comme pour l'édition traditionnelle

Que tu cherches un logiciel pour autoédition compatible avec KDP, Bookelis ou Lulu, ou que tu prépares un manuscrit pour une maison d'édition traditionnelle, Studio Roman couvre les deux flux. L'export EPUB 3 est validé par epubcheck avant écriture du fichier — tes uploads passent du premier coup. L'export PDF supporte le profil PDF/X-1a, exigé par la plupart des imprimeurs professionnels pour l'impression offset.

Confidentialité : un choix de design, pas une option marketing

Le positionnement local-first de Studio Roman n'est pas un argument de vente après-coup : c'est l'architecture même du logiciel. Aucun compte n'est créé sur un serveur tiers. Aucune télémétrie n'est envoyée. Le code est ouvert sur GitHub : tu peux vérifier toi-même, ou demander à un développeur de le faire. Pour qui prend ses textes au sérieux, cette différence change tout.

Questions fréquentes

Réponses rapides

Studio Roman est-il vraiment gratuit, IA comprise ?

Oui, totalement. Pas d'abonnement, pas d'achat in-app, pas de version « premium ». Le code est open-source. Et tu peux utiliser toutes les fonctions IA gratuitement avec Ollama en local — sans carte bancaire, sans connexion internet. Si tu préfères la qualité supérieure d'OpenAI, Anthropic ou Gemini, tu paies directement le fournisseur avec ta propre clé API. Studio Roman ne prélève jamais rien.

Studio Roman est-il en version stable ?

Studio Roman est actuellement en phase de test alpha. Le logiciel est utilisable sur de vrais projets — j'écris moi-même avec — mais des bugs sont possibles et l'interface peut évoluer. Tu peux signaler tout problème par email via hypnomodame@gmail.com. Chaque retour fait avancer le projet.

Comment activer l'IA gratuitement avec Ollama ?

Installe Ollama sur ton PC (gratuit, open-source), télécharge un modèle libre depuis l'invite Ollama (par ex. ollama pull llama3 ou mistral), puis lance Studio Roman. Le logiciel détecte Ollama automatiquement au démarrage. Tu peux ensuite utiliser toutes les fonctions IA — superprompts, suggestions de cohérence, reformulations — sans connexion internet et sans rien payer.

Est-ce une vraie alternative à Scrivener pour le français ?

Oui. Studio Roman propose les fonctions essentielles de Scrivener (structure chapitre/scène, fiches personnages, exports professionnels) et ajoute ce qui manque côté français : Gramalecte et LanguageTool intégrés, interface 100 % francophone, bible d'univers riche, carte du monde interactive. Et c'est gratuit.

Mes textes sont-ils envoyés sur des serveurs ?

Non. Tes manuscrits sont stockés dans une base SQLite sur ton disque dur, point. Aucune télémétrie, aucun envoi automatique. La sauvegarde Google Drive ou Dropbox est désactivée par défaut, et si tu l'actives, le fichier va directement de ton PC vers ton compte personnel — Studio Roman n'a pas accès à ton compte.

Puis-je utiliser Studio Roman sans IA ?

Bien sûr. L'IA est un assistant facultatif. Tous les modules — éditeur, structure, correcteur, fiches, bible, exports — fonctionnent intégralement sans IA. Tu actives l'assistant uniquement si tu le souhaites.

Quels formats puis-je exporter ?

DOCX (Word, pour ton éditeur ou ton bêta-lecteur), EPUB 3 (livre numérique pour Kobo, Kindle, etc., validé par epubcheck), et PDF avec validation PDF/X-1a pour l'impression professionnelle.

Sur quel système Studio Roman fonctionne-t-il ?

Windows 10 et Windows 11 (64 bits). Une version macOS est à l'étude.

Le correcteur fonctionne-t-il hors-ligne ?

Oui. Gramalecte et LanguageTool sont embarqués dans l'application. Aucune connexion internet n'est nécessaire pour corriger ton texte.

Studio Roman convient-il à un auteur autoédité ?

Très bien. L'export EPUB validé et l'export PDF imprimable couvrent les besoins de KDP, Bookelis, Lulu, et de la plupart des imprimeurs. Le module Kit Média aide à préparer la communication autour de la sortie.

Puis-je importer un manuscrit existant ?

Oui. Studio Roman importe DOCX, EPUB et PDF. La structure (titres, chapitres) est détectée automatiquement quand elle est présente dans le fichier source.
