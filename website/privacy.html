Politique de confidentialité — Studio Roman

Dernière mise à jour : avril 2026

1. Nature de l'application

Studio Roman est une application desktop locale (architecture local-first). Vos données (textes, personnages, bible de l'univers) sont stockées exclusivement sur votre appareil, dans une base SQLite locale. Aucun compte utilisateur n'est créé sur un serveur tiers.

2. Aucune collecte par nos soins

Nous ne collectons pas, ne stockons pas et ne traitons pas vos données personnelles sur un serveur distant. Il n'existe pas de base de données centralisée contenant vos écrits ou votre identité.

3. Sauvegarde cloud optionnelle

Si vous activez la sauvegarde sur Google Drive ou Dropbox, la connexion se fait directement entre votre appareil et ces services, via leur page d'autorisation officielle. Un fichier de sauvegarde est envoyé vers votre propre compte. Studio Roman n'a pas accès à ce compte ni à ces fichiers.

4. Prestataires IA (optionnels)

Si vous activez un fournisseur IA cloud (OpenAI, Anthropic, Google Gemini), les extraits de texte que vous soumettez sont transmis à l'API correspondante selon sa propre politique de confidentialité. Studio Roman ne conserve pas ces échanges en dehors de votre session locale. L'utilisation d'Ollama (IA locale) n'entraîne aucune transmission réseau.

5. Cookies et suivi

Studio Roman n'utilise pas de cookies de suivi ni de publicité. Le stockage local est utilisé uniquement pour enregistrer vos projets et préférences sur votre appareil.

6. Vos droits RGPD

Même en contexte desktop, vous disposez des droits suivants sur les données stockées localement :

Droit d'accès et portabilité — Exportez l'intégralité de vos données (personnages, bible) au format JSON :

GET /api/v1/user/export → téléchargement du fichier studio-roman-user-export-[date].json

Droit à l'effacement — Supprimez toutes vos données de l'espace de travail local :

DELETE /api/v1/user/me → suppression des tables personnages et bible (irréversible)

Ces endpoints sont accessibles uniquement depuis l'appareil local (loopback 127.0.0.1). Ils n'agissent que sur la base SQLite locale — aucune donnée distante n'est affectée.

7. Hébergement et logs

L'application peut être distribuée via des plateformes tierces (GitHub Releases, etc.). Ces plateformes peuvent collecter des données techniques (adresse IP, logs de téléchargement) conformément à leur propre politique. Le contenu de vos projets n'est jamais transmis lors du téléchargement de l'application.

8. Contact

Pour toute question relative à cette politique, contactez le développeur via les informations disponibles sur le dépôt du projet.
